# Jana S — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `style.css` — design and responsive styling
- `script.js` — typing animation, mobile menu and reveal animations
- `assets/profile.jpg` — profile photo

## Run
No installation is required.

1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.

## Customize
- Replace the project descriptions in `index.html` with your final project details.
- Add your GitHub and LinkedIn URLs when you have them.
- When your resume is ready, add `resume.pdf` and create a Resume button linking to it.
- Change skills/proficiency percentages in the Skills section if needed.

## Publish
This folder can be uploaded to GitHub Pages, Netlify or Vercel as a static site.
